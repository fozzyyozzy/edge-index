1. NFLVERSE (BEST FREE SOURCE - USE THIS FIRST)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
What: Clean NFL data maintained by the R nflverse community
Coverage: 2000-2025, weekly player stats, play-by-play
Cost: FREE, no API key needed
Format: CSV downloads from GitHub releases

Key datasets:
  Player stats (weekly):
  https://github.com/nflverse/nflverse-data/releases/download/player_stats/player_stats.csv
  
  Snap counts (weekly):
  https://github.com/nflverse/nflverse-data/releases/download/snap_counts/snap_counts_2024.csv
  
  Next gen stats (targets, routes run, air yards):
  https://github.com/nflverse/nflverse-data/releases/download/nextgen_stats/ngs_receiving_2024.csv

Columns we care about:
  player_name, recent_team, season, week,
  targets, receptions, receiving_yards,   ← WR/TE/RB
  carries, rushing_yards,                  ← RB
  completions, passing_yards, attempts,    ← QB
  target_share, snap_pct,                 ← usage selectors
  air_yards_share, wopr                   ← advanced usage

3. PLAYER SELECTION BY USAGE — THE RIGHT WAY
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

For each season, select players by:

WR (top 50):  target_share >= 12% AND snap_pct >= 55%
QB (top 20):  attempts >= 25/game AND snap_pct >= 85%
RB (top 30):  carries >= 8/game OR rec_targets >= 3/game
TE (top 15):  target_share >= 10% AND snap_pct >= 50%

This gives you EXACTLY the players who have lines posted
every week — no more, no less. Usage drives line availability.
